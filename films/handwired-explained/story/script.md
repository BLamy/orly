# Promises, Not Proofs
*How a program becomes a hand-wired neural network, told in the things people were sure of*

> Handwired lets you write a JavaScript interface as builder code that becomes a neural network with every weight written by hand. It runs every operation every frame, cannot stop early, and matches JavaScript exactly, as long as nobody lies to it. Told through the beliefs tied onto its wires like paper tags (who tied each one on, who doubted it, how long it held), the film teaches how the machine really computes: two ramps for every if, a clockwork for every loop, a valve for every gradient. And it meets a lab that writes its doubts beside its certainties, and breaks them on a schedule.

## Chapter 1 — Four and a Half

*A copper thread becomes the wire under a paper desk. The desk is one neural network, and its Monitor window shows that network to itself: 234 state cells, 4,646 operations, 493 outputs, and a wallpaper with one arc for each of its 9,909 weights. ## Chapter 2 — The Oldest Tags

*Framing only, said once in narration: the repo never cites the 1943 work. In 1943 McCulloch and Pitts tie on the oldest tag, the neuron as logic; their units fire against fixed thresholds and learn nothing. In 1951 Kleene shows such a net is a finite machine whose patterns are regular events; the film's own reading: a finite net can only remember so much, so anything unbounded has to come from outside. In 2020, branches of a single human neuron are caught answering either input but not both (XOR), which no lone threshold gate can, and the tag's thread splits: as biology it frays, as engineering it never came down. A younger tag, 2019: learn the weights, don't write them, with Sutton for and Brooks against. Some kept writing weights anyway (Siegelmann and Sontag, Tracr, Giannou et al., Percepta). Then the echo, not lineage: eighty-three years on, someone has written a network's weights by hand to run a desktop.*
