# The Lowest Fifth

- **Paper:** [Does On-Policy Distillation Really Distill? From Noisy Teacher to Self-Improvement](https://arxiv.org/abs/2608.31046) by Yi Ding and Ruqi Zhang
- **Stable identifier:** `arXiv:2608.31046` · DOI `10.48550/arXiv.2608.31046`
- **Daily Paper:** [Hugging Face paper page](https://huggingface.co/papers/2608.31046) · selected at rank 1 with 115 visible upvotes from the [2026-09-01 ranking](https://huggingface.co/papers/date/2026-09-01)
- **Canonical paper:** [abstract](https://arxiv.org/abs/2608.31046) · [PDF](https://arxiv.org/pdf/2608.31046)
- **Official source:** [DripNowhy/On-Policy-Self-Adaptation](https://github.com/DripNowhy/On-Policy-Self-Adaptation) at source commit [`822d3b1`](https://github.com/DripNowhy/On-Policy-Self-Adaptation/tree/822d3b152afe8e9d29c389c5ebc428414f97c10f)

On-policy distillation appears to offer a dense teacher score for every token generated by a student. The paper asks whether that teacher score is really the useful part. Its measurements find substantial teacher-supervision noise, weak sensitivity to removing that noise, and a simpler mechanism underneath: learning concentrates on the sampled tokens the student itself considered least likely. The released On-Policy Self-Adaptation implementation turns that observation into a teacher-free selector and loss mask.

## 1. The Teacher Is Not the Signal

### Teacher noise exposes a student-owned training signal

The teacher evaluates trajectories sampled from the student, so those trajectories are on-policy for the student but off-policy for the teacher. The paper reports that teacher supervision becomes noisy and that larger teachers can produce more noise, yet removing noisy scores does not materially change the student's convergence. A fixed negative advantage on the same low-log-probability tokens can match the teacher-based behavior, which points away from privileged teacher knowledge and toward suppression of the student's own tail tokens.

The repository encodes that boundary directly. [`requires_reference_model`](https://github.com/DripNowhy/On-Policy-Self-Adaptation/blob/822d3b152afe8e9d29c389c5ebc428414f97c10f/slime/slime/backends/megatron_utils/opsa.py) returns false for the OPSA estimator, while [`validate_opsa_args`](https://github.com/DripNowhy/On-Policy-Self-Adaptation/blob/822d3b152afe8e9d29c389c5ebc428414f97c10f/slime/slime/backends/megatron_utils/opsa.py) rejects reference-model Kullback-Leibler loss and the on-policy-distillation path. The final method therefore uses neither a teacher forward pass nor a task reward.

## 2. The Packed-Batch Selector

### A stable sort cuts one exact lowest-probability fifth

[`compute_opsa`](https://github.com/DripNowhy/On-Policy-Self-Adaptation/blob/822d3b152afe8e9d29c389c5ebc428414f97c10f/slime/slime/backends/megatron_utils/opsa.py) treats all valid response tokens in one data-parallel worker's packed batch as a single ribbon. It concatenates actor log probabilities and the original loss masks, keeps only valid positions, and sorts them in ascending order with a stable sort. For (N) valid tokens and fraction (f), it selects `max(1, floor(fN))` whenever the batch is nonempty. The canonical launcher sets (f=0.2).

{% viz scene="books/on-policy-self-adaptation/chapter-2" section="chapter-2-lowest-fifth" cue="0" from="0.000" to="60.464" title="A stable sort cuts one exact lowest-probability fifth." %}
{% endviz %}

Selection is batch-local rather than answer-local. That matters because one unusually improbable token can compete with tokens from every other packed response on the same worker. The selected indices receive ones in a new OPSA mask; unselected response tokens and already-masked prompt positions receive zeros. The implementation then splits the flattened tensors back to the shapes of their original samples.

## 3. Entropy Sets the Pressure

### The actor's uncertainty grades each selected negative advantage

Selection says where to train; actor entropy says how strong the negative advantage should be. Among the selected tokens, the implementation min-max normalizes entropy into a rank (r), then computes (A=A_{max}+(A_{min}-A_{max})r). The canonical values are (A_{max}=-0.5) and (A_{min}=-1.0), so a higher-entropy selected position receives the more negative signal. If every selected entropy is equal, the code assigns rank one and therefore negative one to every selected token.

{% viz scene="books/on-policy-self-adaptation/chapter-3" section="chapter-3-entropy-pressure" cue="0" from="0.000" to="62.090" title="The actor's uncertainty grades each selected negative advantage." %}
{% endviz %}

The mechanism does not threshold entropy or add a separate entropy-reward term. Entropy only ranks the tokens that the actor-log-probability selector has already chosen. Negative advantage suppresses those sampled tail tokens; as their probability decreases, the policy distribution renormalizes. Every unselected token remains at zero advantage and is excluded from both the policy-loss mask and its denominator.

## 4. The Closed Training Loop

### The selector becomes one step inside ordinary actor training

The integration lives in [`loss.py`](https://github.com/DripNowhy/On-Policy-Self-Adaptation/blob/822d3b152afe8e9d29c389c5ebc428414f97c10f/slime/slime/backends/megatron_utils/loss.py). The current Megatron actor recomputes sampled-token log probabilities and, in entropy mode, actor entropy. Context-parallel response tensors are gathered before `compute_opsa` runs over the complete local packed batch. Its advantages and `opsa_loss_mask` then flow through the standard context-parallel slicing and policy-loss reduction before the actor update produces the policy used for the next rollout.

{% endviz %}

The manuscript reports that Qwen3-1.7B rises from 13.44 to 48.85 Avg@32 on AIME24 and from 40.00 to 80.00 Pass@32, with gains on AIME25 and HMMT25 as well. Those are paper results, not a rerun performed for this explainer. The repository's own validation note is narrower: the selector and launchers are covered by processor and command-line checks, while the cleaned open-source configurations have not been freshly reproduced end to end on graphics processors.
