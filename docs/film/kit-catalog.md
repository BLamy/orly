# Film kit catalogue

_Generated by `tools/film/kit-catalog.mjs` from module headers; do not edit by hand._

Everything is importable from `apps/bookshelf/src/viz/film` (the barrel). Painters are `(c, opts, env: PaintEnv)` and draw in the
current layer's rest-screen coordinates; see the `film-shot` skill for the shot contract and paint order. Galleries for every
piece: `http://127.0.0.1:5199/film-gallery.html?g=<name>` (`npm run film:dev`).

## Palette & moods

### `silhouette/palette.ts`

Film palettes (style bible §2). Every mood shares one CIELAB lightness
ladder; only hue/chroma change. Values come from palettes.json, generated by
tools/film/palette.mjs — regenerate rather than hand-edit.

  mood('duskRose')                       -> Palette
  crossfadeMood('labGreen','winterBlue', u)  -> Palette (Lab interpolation, every token)
  mixLab(a, b, u)                        -> hex
  hazed(palette, role, haze)             -> the fill for a role at a layer's haze amount
  makeEnv({ mood, layer, t, ... })       -> a PaintEnv (galleries, tests, core Frame)

Exports: `MOODS`, `MOOD_IDS`, `mood`, `mixLab`, `crossfadeMood`, `hazed`, `makeEnv`, `withAlpha`

## Atmosphere

### `silhouette/atmosphere.ts`

Atmosphere painters (style bible §2.4–2.5, §10.19): the ambient life of a held frame.
Every painter is a pure function of (env.t, env.seed, opts): no state, no Math.random.
Draw them inside `f.layer(...)` (world space of that layer) or screen-locked; `area`
(default: the stage plus a 40 px overscan) is the world rect particles live and wrap in.
Light-like effects (dust, rays, embers, snow, rain) are drawn additively/screen and are
never hazed; smoke/fog/paper take their tone from env.mood.

  dustMotes(c, { beam?, count, drift, size }, env)        motes, bright inside a light beam
  godRays(c, { beams, intensity, mullions, shimmer }, env)  volumetric shafts from openings
      (beams are baked once per geometry: keep them static, animate `intensity` instead)
  windowBeam(rect, dir, length, spread)                   -> Beam from a window opening
  snow(c, { count, wind, fall, gust, settle }, env)       depth-layered snow, optional settling bank
  rain(c, { count, angle, speed, splashY }, env)          streaks in 3 depth bands + splashes
  embers(c, { x, y, spread, count, rise }, env)           rising, cooling sparks from a fire
  sparks(c, { x, y, t0, count, speed, gravity }, env)     one ballistic burst at t0 (forge, short)
  smoke(c, { x, y, kind: 'candle'|'pipe'|'steam'|'chimney', height, drift }, env)
  paperSheets(c, { count, size, wind, fall, tone }, env)  tumbling cut-paper sheets (moves on twos)
  fogBank(c, { y, height, speed, density, layers }, env)  rolling billowed fog (baked, scrolled)

Noise helpers shared by finish/transitions: hash1, vnoise, fbm, vnoise2, fbm2, smoothstep,
softSprite(color) (cached radial disc), makeCanvas(w, h).

Exports: `hash1`, `vnoise`, `fbm`, `vnoise2`, `fbm2`, `smoothstep`, `makeCanvas`, `softSprite`, `windowBeam`, `beamCoverage`, `dustMotes`, `godRays`, `snow`, `rain`, `embers`, `sparks`, `smoke`, `paperSheets`, `fogBank`

## Finish

### `silhouette/finish.ts`

Finish pass (style bible §2.5, §8): bloom, film grain, vignette, exposure flicker,
dust specks/hairs, optional screen-locked paper. Pure function of (frame, t, seed).

  filmFinish(out, env)                      the default FinishFn (bible numbers)
  makeFilmFinish({ bloom, grain, vignette, flicker, paper, dust }) -> FinishFn
      every option is a MULTIPLIER of the bible default (1 = default, 0 = off), except
      paper (screen-locked paper alpha, default 0; parchment plates ≈ 0.25).
  env.bloom / env.grain / env.vignette (FinishFn env) also multiply the defaults.

`out` is the composed frame at device resolution. Bloom reads `out.canvas` itself; when
the finish is drawn on a separate transparent canvas, call bloomPass(sceneCtx, ...) on the
scene canvas and pass { bloom: 0 } to the overlay finish. All passes reset to identity.

Helpers: bloomPass, grainPass, vignettePass, flickerPass, dustPass, gateWeave(frame, fps, seed)
(x ±0.6 / y ±0.8 px @1080p, on twos; core applies it as a plate offset), paperPattern(c),
paperTexture(c, rect, { alpha, offset }) for layer-locked paper fibre on L0–L3 (soft-light).
Budget: ≈2–4 ms at 1080p (one quarter-res filtered copy, three full-frame fills).

Exports: `bloomPass`, `grainPass`, `vignettePass`, `flickerAmount`, `flickerPass`, `gateWeave`, `dustPass`, `paperTile`, `paperPattern`, `paperTexture`, `makeFilmFinish`, `filmFinish`

## Transitions

### `silhouette/transitions.ts`

Transitions (style bible §9). TransitionFn(out, a, b, u, env): composite already-rendered
frames a (outgoing) and b (incoming), u 0 -> 1. `out` is device resolution; a/b are the
same size; every function resets `out` to identity itself. Pure in (u, env.seed, env.frame).

  TRANSITIONS: Record<TransitionKind, TransitionFn>
    cut          hard cut at u = 0.5
    crossfade    smootherstep dissolve
    iris         feathered iris closes on A to black, holds, opens on B (0.8–1.2 s each way)
    inkBleed     B spreads like ink through paper fibres, with a wet ink edge (1.5–2.5 s)
    paperWipe    A is torn away along a ragged cut-paper edge, casting a soft shadow on B
    fadeBlack    fade through the mood's fg black
    lampChange   the lamp dims (warming as it goes) to black, then relights on B with a
                 theatre-lamp stutter (1.5 s down, 1.5 s up = 3 s total)
  Factories for staged variants (centre on a practical light, choose an origin/direction):
    makeIris({ closeAt, openAt, hold, feather })   points in stage px (1280x720)
    makeInkBleed({ origin, edge, wet })            origin in stage px
    makePaperWipe({ dir: 'right' | 'left', slant })
  warmTransitions(w, h, seed) precomputes the ink field (~40 ms once) so no frame stalls.
Per-frame cost at 1080p: one or two full-frame copies + a 480x270 mask (ink bleed ≈ 2 ms).

Exports: `makeIris`, `warmTransitions`, `makeInkBleed`, `makePaperWipe`, `iris`, `inkBleed`, `paperWipe`, `TRANSITIONS`, `TRANSITION_DUR`

## Typography

### `silhouette/type.ts`

Film typography (style bible §7). Self-hosted Google Fonts (public/fonts/film/fonts.css).
Canvas painters in STAGE px (1280x720, screen-locked: paint after the layers). Every card
has its own envelope: `at` (start, shot-local s), `dur` (on-screen time incl. fades;
default: stays), `fade` (s). Sizes respect the 26 px @1080p floor (≥ 17.4 stage px).

  await loadFilmFonts()                       inject fonts.css (if missing) + document.fonts.load(FILM_FONTS)
  FILM_FONTS / FONT                           preload specs / family names
  titleCard(c, { title, subtitle?, kicker?, backlit? }, env)       film title: Cormorant 600 + fleuron rule
  chapterCard(c, { number, title, dates?, label? }, env)           "CHAPTER III" + rules + title
  placeStamp(c, { place, date, year?, style? }, env)               era-adaptive type-on stamp, bottom-left
       style auto from year: < 1970 typewriter (Special Elite) · < 1990 phosphor (VT323) · else mono (Plex)
  nameCard(c, { name, role, years? }, env)                         lower third, 3.5 s default
  quoteCard(c, { quote, speaker, source? }, env)                   verbatim quote, ≤ 42 chars/line
  annotation(c, { text, x, y, tx, ty, sub?, onParchment? }, env)   label + leader line to (x,y)
  rule(c, x, y, w, { ornament, color, grow }) · fleuron(c, x, y, size, color) · roman(n)
  envelope(t, at, dur, fade) -> 0..1 · drawTracked(c, text, x, y, { font, size, tracking, align })
env: anything with { t, mood } (a PaintEnv works). Colours come from the mood: titles in
`core`, body in warm parchment, ink on parchment plates.

Exports: `FONT`, `FILM_FONTS`, `loadFilmFonts`, `envelope`, `roman`, `measureTracked`, `drawTracked`, `wrapLines`, `softPlate`, `textColor`, `titleColor`, `fleuron`, `rule`, `titleCard`, `chapterCard`, `stampStyleFor`, `placeStamp`, `nameCard`, `quoteCard`, `annotation`

### `silhouette/overlays.tsx`

SVG overlay components (stage coordinates, 1280x720) for ShotModule.overlay(): ink on
parchment, rendered above the scene canvas and below the finish pass.

  <ParchmentPlate x y width height seed? opacity? lift? title?>{children}</ParchmentPlate>
      a deckled cut-paper card: fibres, foxed edges, a double engraved border, corner lozenges
  <EquationPlate tex x y width? height? fontSize? caption? number? reveal? opacity? seed?/>

Exports: `ParchmentPlate`, `EquationPlate`, `InkCaption`

## Ornament & lathe

### `silhouette/ornament.ts`

Ornament: Path2D builders for period detail (style bible §5 "pierced detail + repeating ornament").
Everything is built at a local origin, cached by parameters, and placed with `at()`/`repeatX()`.
Solid shapes are wound clockwise; `ccw` contours inside them become holes (nonzero or evenodd).

  addCircle/addEllipse/addRect/addPoly(p, ..., ccw?)   contour appenders (for building holes)
  addFoil(p, cx, cy, r, n, {rot, lobe, ccw})          cusped n-foil contour (trefoil n=3, quatrefoil 4)
  ribbon(pts, widths)                  closed polygon around a centre line (variable width)
Shapes (origin noted)
  foil(r, n, rot?)                     solid n-foil, centred
  roundel(r, n)                        ring with a foiled hole (gothic tracery eye), centred
  rosette(r, petals)                   pierced rosette, centred
  volute(r, {turns, width, dir})       spiral ribbon ending in an eye, centre of spiral at 0,0
  scroll({w, h, kind:'C'|'S', thick})  C- or S-scroll spanning (0,0)->(w,0), curls bulging up (-y) by h
  acanthus({len, w, curl, lobes})      leaf from base (0,0) growing up, pierced midrib + eyes
  palmette({r, leaves})                anthemion fan above (0,0), non-overlapping (safe as holes)
  pinnacle({h, w, crockets})           gothic crocketed spire, base centre (0,0)
  finial(kind, h)                      'ball'|'acorn'|'urn'|'flameUrn'|'spire', base centre
  scallopEdge({w, h, pitch, depth, eyelets})  lace band, top-left (0,0)
  tasselFringe({w, pitch, len, band})  braid + tassels, top-left (0,0)
  balustrade({w, h, pitch, rail, plinth, slim}) rail+balusters+plinth, bottom-left (0,0), up is -y
  eggAndDart({w, h})                   pierced moulding band, top-left (0,0)
  dentils({w, h, pitch})               toothed band, top-left (0,0)

  ornateFrame({w, h, crest, apron})    pierced frame with crest; opening is a hole; top-left (0,0 …

### `silhouette/lathe.ts`

Lathe: turned silhouettes from a half-profile mirrored about a vertical axis.

  lathe(segs, { anchor })            -> Turning { path, h, w, profile }   (cached by segs)
  turning(kind, h, w?)               -> Turning for a preset:
      'baluster' 'balusterSlim' 'candlestick' 'candlestickTall' 'vase' 'urn' 'chairLeg'
      'column' 'lampBase' 'finial' 'finialAcorn' 'bedpost' 'newel' 'goblet' 'flask' 'beaker' 'bottle'
  drawTurning(c, { kind|segs, x, y, h, w?, role? }, env)   painter; (x, y) = base centre (anchor 'bottom')
  placeTurning(p, t, x, y, sx?, sy?)  add a Turning's path into a bigger Path2D at (x, y)

Segments run top -> bottom; r is the half-width. Consecutive segments may jump in r
(a step / fillet). Shapes: ['cyl',h,r] ['taper',h,r0,r1] ['flare',h,r0,r1] (convex)
['cove',h,r0,r1] (concave) ['ogee',h,r0,r1] (S) ['bead',h,r,rEnd?] ['vase',h,r0,rMax,r1,at?]
['point',h,r0] (to a tip) ['gap',h] (zero-width neck, splits the outline).
Paths are built with anchor 'bottom' by default: base at y = 0, extending to y = -h.

Exports: `lathe`, `presetSegs`, `turning`, `placeTurning`, `drawTurning`

### `silhouette/puppet/index.ts`

Articulated silhouette puppets (style bible §4) — the cut-paper cast.

Spec notes
 - wardrobe: a WARDROBES name (wardrobe.ts). Append ':f' / ':m' to choose the
   figure explicitly ('hoodie:f'); skirts and dresses default to 'f'.

 - details: extra cut-line ids put first in the ≤ 8 budget (e.g. 'watchChain', 'crease').

in env.fill('rim') at α .3–.55 in each part's local space, lenses lit. Facing 'left'

watch chain), never mirroring them. Secondary parts (hair falls, skirts and coat
hems, ties, hood strings, lanyards) hang by gravity and lag one twos-tick at 0.6
when the pose carries `prev` (poseTrack / walk / withLife do this for you).
Root: pose.root.x is FORWARD-relative stage px; pose.root.y (stage px, + = down)
disables auto-grounding (otherwise the lowest heel/toe sits on y).

walk (walkCycle …), WARDROBES, HAIR_STYLES, ERA_CAST (a ready line-up).

### `silhouette/puppet/rig.ts`

Puppet rig core (style bible §4.2): units, the rig tree + draw order, joint
limits, 2D affine math and the smooth-outline path builder every part uses.

Units: a puppet is authored facing RIGHT in "figure units" where the whole
adult is UNIT_H = 300 tall (head = 40 → 7.5 heads), feet on y = 0, +x
forward, +y down. Each part is a Path2D in its own local space with its pivot
at the origin; limbs hang along +y. createPuppet (index.ts) scales by
spec.height / UNIT_H and flips the whole rig for facing 'left' (asymmetric
details are re-chosen per facing, so a flip never moves a pocket or a part).

Joint angles are degrees, positive = forward:
  torso/neck/head: lean or nod forward (face goes down)
  shoulder/elbow/wrist/hip: the distal end swings forward
  knee: negative = shin swings back (bends)   ankle: positive = toes up
Limits (clampPose) follow the bible, re-signed to "positive = forward":
  shoulder −70…+175, elbow 0…160 (cut-out cheat for hand-to-chin), wrist −60…60, hip −45…+100,
  knee −150…0, ankle −40…+35, neck/head −25…25, torso −15…+20.

  smooth(pts, { closed, path })  Catmull-Rom style outline through points
      [x, y] or [x, y, s] where s ∈ 0..1 is the local smoothness (0 = corner)
  M (affine [a b c d e f]): mIdentity, mMul, mTranslate, mRotate, mScale, mApply

## Teaching machines (metaphors)

### `silhouette/metaphors/index.ts`

Teaching machines (style bible §6): neural-network ideas drawn in the silhouette

  lanternNetwork   neurons = paper lanterns, weights = loom strings; XOR trained offline
                   params: epoch, sample, wave, back, reveal

### `silhouette/metaphors/mistyHills.ts`

mistyHills — gradient descent as a lantern-bearing traveller crossing misty hills.
The front ridge IS the loss curve of a closed-form function (below); the traveller
stands at the current iterate and every stride is one real gradient step
x <- x - lr * f'(x), precomputed per learning rate.
  lantern light radius  <- what the traveller can know: only the local slope
  lit tangent + arrow   <- f'(x) and the actual step lr * f'(x)
  stride / leap length  <- lr * |f'(x)| ; fog <- you cannot see the global minimum
Landscape: f(x) = 0.04x² + 1.8 − 0.8·exp(−(x+3)²/0.5) − 1.9·exp(−(x−2.2)²/6)
  local minimum (the trap) x ≈ −2.91, f ≈ 1.33 ; global minimum x ≈ 1.96, f ≈ 0.07
Verified paths from x0 = −5.3: lr 0.2 walks into the trap and stays; lr 1.8 leaps the
ridge and settles in the valley by step ~15; lr 3.5 overshoots forever (0.76 <-> 2.81).

  mistyHills(c, {
    x?, y?, w?, h?    box (default the full stage)
    lr: number        learning rate (MISTY_LR.timid | .bold | .reckless or any)
    x0?: number       start (default −5.3)
    step: number      iterate index, fractional = mid-stride
    fog?: number      0..1 fog over the hills (lantern clears a pool around itself)
    tangent?: number  0..1 show the lit tangent and the step arrow
    trail?: boolean   cairns at past iterates
    labels?: boolean  "learning rate · step · loss" under the scene
    reveal?: number   0..1 hills rise, traveller appears
  }, env)
  descentPath(lr, x0?, n?) -> number[] ; lossF(x), lossDf(x)

Exports: `lossF`, `lossDf`, `MISTY_LR`, `MISTY_MINIMA`, `descentPath`, `mistyHills`

### `silhouette/metaphors/perceptronMath.ts`

Rosenblatt's perceptron (Mark I organisation), computed for real at module scope.

  S-units: a 20x20 photocell retina (binary pixels)
  A-units: N_A association units, each wired at random to a few retina cells
           (+1 excitatory / -1 inhibitory), firing when the sum reaches its threshold
  R-unit:  one response unit: fires (+1) if sum_a w_a·a + w_0 > 0, else -1
  rule:    on a mistake, w <- w + eta·target·a  (only the A-units that fired move)

The task: tell HORIZONTAL bars (target +1) from VERTICAL bars (target -1) of
random length, jittered around the centre of the retina. Verified offline
(wiring seed 101, presentation seed 1958, eta 1): held-out accuracy on 400 fresh
images is ~0.67 after 10 presentations, ~0.95 after 40 and ~0.99 after 120.
(A square-vs-circle task at random positions does NOT train with these local
A-units: it stays near chance, the translation problem Minsky & Papert stressed.)
Exports the full training record so a painter can scrub it with a `step` param.

Exports: `RETINA`, `N_A`, `FAN_IN`, `TASK`, `TASK_NAMES`, `JITTER`, `makeImage`, `makeAUnits`, `aOutputs`, `trainPerceptron`, `testAccuracy`, `PERCEPTRON_RUN`, `perceptronAccuracy`
