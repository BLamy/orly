# Authoring a film shot

Read first: `docs/film/ARCHITECTURE.md` (§4 timing, §5 engine), `apps/bookshelf/src/viz/film/contracts.ts`,
and the style bible `docs/film/research/silhouette-style-bible.md` (§2 palette & light, §3 depth,
§4 puppets, §5 props, §6 metaphors, §10 don'ts). The visual target is
`.orly-work/reference/silhouette-reference.png`. Code and story are written by Claude Opus 5.5 only.

## Files

```
apps/bookshelf/src/viz/films/<slug>/
  timeline.json        GENERATED by generator/film/timeline.mjs — the locked clock. Never edit.
  cast.ts              export const cast = { <id>: createPuppet(spec) } (from story/script.json cast)
  sets/<name>.ts       shared recurring sets for this film
  shots/<shotId>.tsx   one module per shot (auto-registered; default export defineShot(...))
```

Everything is exported from `apps/bookshelf/src/viz/film` (the barrel imports `./setup`, which
registers the kit's transitions, finish pass and fonts). `Timeline`, `ease` come from `apps/bookshelf/src/viz/core`.

## The shot module

```tsx
import { Timeline, ease } from '../../../core';
import { CAMERA3_HOME, LAYERS, cam3Interp, camMove, overscan, defineShot } from '../../../film';
import type { Camera3 } from '../../../film';

const END = camMove(90, 140);                       // truck right 90, dolly in 140 over the shot
export default defineShot({
  id: 'ch02-s03',
  mood: 'labGreen',                                 // the shot's palette (script.json shot.mood)
  build({ timing: T }) {                            // T = ShotTiming from the locked clock
    const tl = new Timeline();
    const cam = tl.channel<Camera3>('cam', CAMERA3_HOME, cam3Interp);
    tl.tween(cam, END, { at: 0, dur: T.duration, ease: ease.move });
    const glow = tl.channel('glow', 0);
    tl.tween(glow, 1, { at: T.word('L0203', 'learn') - 0.2, dur: 0.8, ease: ease.enter });
    tl.hold(0, T.duration);                         // the timeline spans the whole shot
    return { tl, cam, glow };
  },
  paint(f, s, scene) {                              // s = scene.tl.sample(t); pure function of t
    f.camera(s.get(scene.cam));
    f.backlight({ sunX: 640 });
    f.layer('L2', (c, env) => { /* back wall with window HOLES (evenodd), cached */ });
    f.fog('A');
    f.layer('L3', (c, env) => { /* furniture / machines */ });
    f.fog('B');
    f.layer('L4', (c, env) => { /* puppets + hero prop: the only sharp plane */ });
    f.rim();                                        // after L4
    f.practical({ x: 900, y: 430, kind: 'lamp', seed: 3, intensity: s.get(scene.glow) });
    f.layer('L5', (c, env) => { /* near floor edge / table end, blurred */ });
    // screen-locked type last: titleCard / placeStamp / nameCard / quoteCard (kit type.ts; they enforce the 22 px cap-height floor)
  },
  overlay(s, scene) { return null; },               // optional React SVG: EquationPlate, ParchmentPlate
});
```

Canonical worked examples: `apps/bookshelf/src/viz/films/_demo/shots/demo-s01.tsx` (every Frame
feature, baked layers with overscan) and `demo-s02.tsx` (snowy street, lamps, transitions), and the
example film `films/perceptron-short`.

## Painter API (Frame)

- Paint order is fixed: `camera → (setMood) → backlight → L1 → L2 → fog A → L3 → fog B → L4 → rim → practicals → L5 → L6 → type`.
- **Rest-screen coordinates:** at `CAMERA3_HOME` a point drawn at (x, y) in ANY layer lands at (x, y) on
  the 1280×720 stage. The layer transform adds true parallax for pan/dolly. Author art wider than the
  frame for camera moves: `overscan(LAYERS.L2, [CAMERA3_HOME, END], pad)` gives the rect to cover.
- `env.fill('ink'|'set'|'fg'|'rim'|'halo'|'core'|'haze')` resolves the hazed colour for the layer —
  never hard-code hex. Windows/doors are **holes** in walls (evenodd) so the backlight shows through.
- `f.cached(key, w, h, draw, {blur?})` bakes static art once at device resolution (blur baked in) and
  returns `drawAt(c, x, y)`. Put the mood id in the key. Static layers MUST be cached.
- `f.practical({x,y,kind:'candle'|'lamp'|'screen'|'led'|'tube',seed,intensity?,radius?,layer?})` — additive glow
  with deterministic flicker (distinct `seed` per light). `f.fog('A'|'B'|{yCenter,height,alpha,drift})`.
- `f.setMood(to, {from, u})` crossfades palettes in Lab (1.5–3 s between sequences).
- Camera grammar: slow (4–12 s eases), ≤ ~6% frame width per second on the action plane; push in on
  the key idea, pull back to reveal scale; lens zoom rarely; one dolly-zoom per film at most.

## Timing — animate to the words

`T.duration`, `T.line(id)` → {start, end, words}, `T.word(lineId, n | 'text' | 'text#2' | -1)`,
`T.wordEnd(...)`, `T.beat(name, fallback?)` (script beats, already resolved), `T.emphasis(minGap=1.2)`
(stressed words for gesture beats). All shot-local seconds. Land each reveal **on the word that names
it** (start 0.1–0.3 s before). Keep `tl.hold()`s so beats breathe. Transitions straddle the cut (±d/2).

## The kit (read each module's header comment for full options)

- **Sets** — `silhouette/architecture`, `silhouette/nature`, `silhouette/ornament`, `silhouette/lathe`:
  gothic window walls with tracery, arches, columns, panelling, bookshelves, staircases, perspective floors,
  lecture hall, colonial hall, 1950s–70s lab, 1980s office, 2012 bedroom, glass office, data-centre aisle,
  city skylines by era, winter trees, ridgelines, snowfields, sky.
- **Props** — `silhouette/props`: candlesticks, lamps, desks, period chairs, tasselled table, books,
  papers, typewriter, phone, chalkboard, Mark I Perceptron, IBM-704-style console, tube racks, CRT,
  workstation, GPU card, server rack, chip, globe, chess/Go boards, newspaper, podium, clock. Each has
  `anchors()` (flame, screen centre, hand grip) — attach `f.practical` there.
- **Puppets** — `silhouette/puppet`: `createPuppet(spec).draw(c, {x, y, facing, pose, scale}, env)`; pose
  library (stand, present, point, write, think, doubt, dissent, triumph, despair, authority, lean, sit, type),
  pose-channel helpers, breathing/idle, `talkBeats(T)`, walk cycle with planted feet. **Puppets move on twos**
  (use `env.tq`); camera/light/fog on ones. No mouths, no eyes, never caricature.
  **Value hierarchy** (review rounds 3-4): the figure is the DARKEST shape in frame. Pass `ink: PUPPET_NEAR_BLACK`
  (#0b0d0b, from `silhouette/puppet`) and light it only on the window side: `light: {x, y, floor: 0}` fades its
  cut-lines away from the key, and `edgeRim: {x, y, px: 1.5}` cuts a 1-2 px rim on its own contour facing (x, y).
  Then rim the SET with `f.rim({ x: 0, y: -1 })` (tops only), so racks and cabinets carry no side or bottom
  strokes; keep set ink one step lighter than the figure. Paint practicals that sit BEHIND the action plane
  (L3 tubes, lamps on the back wall) before the L4 layer: painted after it, their halos wash over the figure.
- **Atmosphere** — godRays(windowBeam(...)), dustMotes, snow (two depth bands around a fog sheet), rain,
  embers, sparks, smoke (candle/pipe/steam/chimney), paperSheets, fogBank.
- **Type** (screen-locked, after layers) — titleCard, chapterCard, placeStamp (typewriter <1970, phosphor
  1970–89, mono after), nameCard (first appearance of a real person), quoteCard (verbatim quotes only),
  annotation. Cap height ≥ 22 px at 1080p (legibleSize); keep the bottom 12% clear.
- **Overlays** (React SVG in `overlay()`) — EquationPlate (KaTeX on parchment), ParchmentPlate, InkCaption.
- **Teaching machines** — `silhouette/metaphors`: lanternNetwork (real XOR training; `epoch`, `wave`, `back`),
  perceptronRetina (`step`), xorPlate (`sweep`, `solve`, `fold`), mistyHills (real gradient descent; `lr`, `step`),
  stencilLantern (real convolution; `step`, `kernel`), alexnetCathedral (+ alexnetResultPlate), threadsOfLight
  (real toy attention; `query`, `heads`), transformerLoom, typeSlugs / nextToken. Draw them inside
  `f.layer('L4', …)`; they draw their own glows. Label illustrative data as illustrative in narration/labels.
- **Transitions** (script `transitionIn`): cut, crossfade, iris, inkBleed, paperWipe, fadeBlack, lampChange.

## Film-wide rules from review round 1 (kit-enforced or audited)

- **Legibility floor:** any text the viewer must read has a cap height of at least **22 px on a 1080p frame**.
  The kit cards enforce it; for your own text use `legibleSize(c, font, size, text?)` / `legibleFont(c, font)` /
  `capPx1080(c, font)` from the type kit (they include the camera and layer scale). When a card is the subject,
  push in. Audit: `node generator/film/legibility.mjs --slug <slug> --shot <id>` (qa/legibility/<id>.json).
- **Depth:** every camera move shows at least **3 depth planes** sliding against each other (add an L5/L6
  occluder or an L1/L2 far plane). Audit: `node generator/film/depth.mjs --slug <slug> --shot <id>`.
- **Puppet signatures:** `PuppetSpec.signature` (stoop, chinUp, hairScale, rim) applies on every draw; a
  shot's own `edgeRim` overrides the default back-top rim.
- **Glossary tags:** script onScreenText kind `term` ({text, gloss, beat}) is painted by the reel (core/terms.ts),
  top-left: keep that corner clear while it shows. Shots never draw it.
- **Screen-locked kit overlays:** `queueOverlay(fn)` (core/paintContext) lets a set draw a label above fog and
  near layers; `paintContext()` tells a painter which shot is painting; `isBaking()` is true inside `f.cached`.
- Film sets may carry film-wide rules of their own (neural-net-history: the candle naming rule in
  sets/beliefCandle.ts, the shared near occluders in sets/occluders.ts, the vellum X-ray in sets/xrayColumn.ts).

## Rules

1. **Pure:** no `Math.random`, `Date.now`, `performance.now`, rAF, CSS animation, d3 transitions. Seeded
   noise only (`hash1`, `vnoise`, `fbm` from the barrel). Precompute geometry at module scope or cache it.
2. **Fast:** the reel budget is ~30 ms per 1080p frame for everything; cache static layers, keep per-frame
   work to channels, puppets, particles and light. Check `window.__film.frameInfo()` in the studio.
3. **Truthful:** on-screen facts come only from the shot's script entry (fact-checked). Real people get a
   name card on first appearance; quotes are verbatim from `research/quotes.json`.
4. **Legible & clean:** one sharp action plane; one saturated accent at most, motivated by a light; no
   text over busy art without a soft plate; endings resolve (fade competing layers ≤ 0.15).
5. **Scoped edits:** only your shot files (and new `sets/<shotId>-*.ts`). Never edit `timeline.json`.

## Verify (every shot, every revision)

```bash
npx tsc -p apps/bookshelf/tsconfig.json --noEmit                       # fix errors in your files
node generator/film/sheets.mjs --slug <slug> --shot <shotId>           # → films/<slug>/qa/sheets/<shotId>.png (a frame every 2 s + every beat)
```

Read the sheet: each frame is labelled with its time and the line being spoken. Check composition, light,
depth, legibility, that each beat lands on its word, and continuity with neighbouring shots. Iterate.
For live review open `http://127.0.0.1:5199/?film-studio=<slug>` (dev server: `npm run film:dev`).
